# A primeira parede

Agora, vamos iniciar o projeto com o seguinte comando:

```bash
npm init
```

O comando acima criará o arquivo `package.json`. Após a criação, deixe-o conforme o exemplo abaixo:

```json
{
  "name": "tabnews-clone",
  "version": "1.0.0",
  "description": "Repositório criado para acompanhar o https://curso.dev",
  "main": "index.js",
  "directories": {
    "doc": "docs"
  },
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "author": "",
  "license": "MIT"
}
```

Em seguida, vamos instalar o **Next.js**, o **React** e o **React DOM** nas versões utilizadas pelo projeto:

```bash
npm install next@13.1.6 react@18.2.0 react-dom@18.2.0
```
